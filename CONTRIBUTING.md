# Contributing

Your contributions are always welcome!

Just send a pull request, and I will review and merge it.

## Guidance

### General

For new items, please follow the existing format.

### Publications

Only include complete papers that are directly related to **Personal Voice Activity Detection (Personal VAD / Speaker-Conditioned VAD)** or **Target-Speaker Voice Activity Detection (TS-VAD)**.

For each paper, please include:
* The **paper title** (with a link to the paper on arXiv, ISCA Archive, IEEE Xplore, etc.)
* **Where the paper was published** (conference, journal, or arXiv)
* The **publication year**

For example, these will **NOT** be accepted:
* Course project reports.
* One-page system descriptions without technical contributions or experimental analysis.
* Commercial system technical documents.
* Media posts.
* Low-quality papers without experiments and evaluations.
* Publications not directly related to Personal VAD or Target-Speaker VAD:
  * Standard speaker-agnostic VAD papers.
  * Pure speaker verification or speaker recognition papers.

### Software

* When adding a GitHub repository to a software table, include the GitHub star badge (`![GitHub stars](https://img.shields.io/github/stars/owner/repo?style=social)`), programming language(s), and a concise description of how it implements or supports Personal VAD or Target-Speaker VAD.
